Residual of a direct native estimate after removing directions known to be uncorrelated with the reference. Base: the complete native level-3 Pauli-path delta 1e-4 vector (all 38 IDs run separately; scored 133/1000). Null directions: complete native MPS chi32 vector (0/1000), complete native MPS chi64 vector (0/1000), and a geometry prior (2/1000). The base was regressed on [1, chi32, chi64, prior] and the residual kept: this removes variance that the scores show cannot be correlated with the reference while preserving the base's own signal. No hidden-circuit reconstruction; the only feedback used is that three whole vectors scored ~0. Values are not expectation values.
